# Package Lock Note

This file explains the `package-lock.json` in this project.

## What is package-lock.json?

The `package-lock.json` file is automatically generated by npm and locks down the exact versions of all dependencies (and their dependencies) used in the project.

## Why is it important?

1. **Consistency**: Ensures everyone working on the project uses the exact same dependency versions
2. **Reproducibility**: Guarantees that `npm install` produces identical results across different environments
3. **Security**: Locks dependencies to specific versions, preventing automatic updates that might introduce vulnerabilities

## Should you commit it?

**Yes!** Always commit `package-lock.json` to version control.

## Common Commands

```bash
# Install dependencies exactly as specified in package-lock.json
npm ci

# Install dependencies (updates package-lock.json if needed)
npm install

# Update a specific package
npm update package-name

# Update all packages (be careful!)
npm update
```

## Best Practices

- Use `npm ci` in CI/CD pipelines for faster, more reliable installs
- Use `npm install` for local development
- Review `package-lock.json` changes in pull requests
- Don't manually edit `package-lock.json`

## Security

Regularly audit dependencies:
```bash
npm audit
npm audit fix
```
